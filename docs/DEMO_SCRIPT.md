# Three-minute demo plan

1. Start a release session and show the artifact digest.
2. Attempt publication before testing; show actual Gateway denial.
3. Run tests and obtain human approval for the exact digest.
4. Substitute a different digest; show denial.
5. Complete a valid release to the sandbox.
6. Inspect the execution trace and authorization events.
7. Generate an evidence-backed incident report.
8. Distinguish a denied attempt from a completed unauthorized publication.

Record only after deployment. Use actual screenshots and traces; mock outputs are not proof of AWS execution.
